# MVP gap follow-up

1. Public Devnet: not yet deployed. Existing private-validator state is preserved. Mainnet remains prohibited. Devnet USDC is a test token, not genuine redeemable USDC. Before deploying a fresh public program, fix the authority-unbound initialization finding recorded in PRODUCTION_LAUNCH.md; do not rely on racing other initializers.
2. Contributor payments: parallel slot bounties already exist in API and the new-bounty form. `structure=slots` divides the gross bounty evenly across 2–20 separate escrow orders; each slot has its own seller, review, settlement and refund lifecycle. This is not an arbitrary weighted split from one shared escrow. For 500 mock USDC with five slots and the default 6% commission, each gross 100 slot yields 94 seller and 6 platform, excluding separately quoted verification/hosting costs. Implementation evidence: `phase5-advanced.test.ts` multi-seller case. Unequal contributor shares require a further protocol/product change.
3. Infringement reports: signed-in listing visitors can submit a good-faith description and HTTPS evidence link. Reports are private, deduplicated while open and rate-limited. Admin moderation includes a review queue; decisions notify the reporter. An upheld report still requires the existing explicit moderation action and any required on-chain signature. Evidence URLs are stored, never fetched by the backend. Tests cover concurrent duplicate prevention, reporter privacy, admin access and no automatic takedown.
4. External alerts: `send-security-alert.mjs` publishes to the existing AWS SNS topic `edgebounty-alerts` (eu-north-1) with the EC2 instance role, after each health check. It is silent while healthy, sends one alert per state change (including recovery) and repeats hourly while unhealthy. Request signing was verified against AWS; delivery is blocked until `edgebounty-ec2-role` is granted `sns:Publish` on that topic. After granting it, run `node scripts/send-security-alert.mjs --test` from the release directory and confirm the email arrives. No mailbox receipt is claimed yet.
