It starts the preserved old frontend, verifies readiness, restores the two replaced API source files, restarts the API, restores/validates Caddy routes, then stops the new frontend and saves PM2 state. It never restores an old database or chain ledger. New agent source files can remain unused once the old route registration is restored.
